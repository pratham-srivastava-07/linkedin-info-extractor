## Architecture (invariant)

Strictly layered, one direction of dependency:

```
Routes → Controllers → Services → Repositories → Prisma
```

- `src/interfaces/` — entity types + DTOs
- `src/validators/` — Zod schemas (+ `index.ts` barrel)
- `src/repositories/` — Prisma data access ONLY; import the client from `helpers/prisma.ts`
- `src/services/` — business logic; throws `AppError` for expected failures (+ barrel)
- `src/controllers/` — parse validated input → call service → shape response (+ barrel)
- `src/routes/` — wire paths to controllers; apply `requireAuth` where needed (+ barrel)
- `prisma/schema.prisma` — models

The **`profile` slice** is the reference implementation. Every other entity mirrors it exactly.
(The generated `user` slice was removed — ProfileLens authenticates callers with a single
static API key, and multi-user is an explicit non-goal in the root `CLAUDE.md`.)

Two folders sit outside the entity layers and are consumed by services:

- `src/linkedin/` — the reverse-engineered Voyager HTTP client, session manager and
  cookie/CSRF handling. **No browser automation belongs here, ever** — the requirement is
  a purely reverse-engineered solution that hits LinkedIn's endpoints directly.
- `src/normalization/` — pure raw-JSON-to-`Profile` mapping. No I/O, no clock, no config;
  everything it needs arrives as an argument. This keeps it unit-testable against fixtures.

## Adding an entity (the 7 touchpoints)

Mirror the `user` slice in the **`class`** idiom this project already uses — match the
existing files, don't invent a new shape:

1. `prisma/schema.prisma` — add the model, then `npm run prisma:migrate`.
2. `src/interfaces/<entity>.ts` — entity type + DTOs.
3. `src/validators/<entity>.ts` — Zod schemas; register in `src/validators/index.ts`.
4. `src/repositories/<entity>.repository.ts` — Prisma access only.
5. `src/services/<entity>.ts` — business logic; register in `src/services/index.ts`.
6. `src/controllers/<entity>.ts` — request/response glue; register in `src/controllers/index.ts`.
7. `src/routes/<entity>.ts` — wire the paths; register in `src/routes/index.ts`.

Keep every barrel (`index.ts`) registered. Prisma is the only data layer — never reach past
the repository.
